# 開啟聊藏

解壓縮整個程式包，按兩下「ChatAtlas.exe」。不需要安裝 Python，也不用輸入密碼。

- 「查看人工範例」：先體驗知識地圖，不會讀取你的 LINE。
- 「整理 LINE」：連接後選取聊天室，再選擇要保留的內容與保存位置。選到尚無收藏的既有父資料夾時，程式會請你確認建立專用私人子資料夾，不修改父資料夾權限。
- 「我的收藏」：開啟已有地圖、檢查檔案或另存完整副本。

目前真實 LINE 採集仍待 Windows 實機驗證。沒有可用的連線設定時，程式會顯示狀態，不會把範例當成你的聊天。

# 閱讀知識地圖

開啟收藏的 `index.html`，點主題、人物或檔案，就能在旁邊讀到相關原文。使用「閱讀內容」看完整對話，使用「圖片與檔案」預覽或另存附件。

關鍵字連結表示原文提到這個詞；不代表程式已判斷它們有因果或其他事實關係。點開原文即可確認脈絡。

把整個收藏資料夾複製到離線電腦後，仍可開啟、搜尋與反覆另存。請保留旁邊的 `assets`、`reader`、`downloads` 資料夾。不能只複製 HTML。

再次整理同一份收藏時，相同訊息會更新，完整舊附件沿用。未取得的歷史不會直接刪除；缺檔、只有預覽圖與尚未保存會分開標示。

# 保存與分享

程式與工作收藏需要支援私人權限的本機位置；雲端同步標記、連結或不支援權限的媒體可能被拒絕。

收藏沒有加密，持有整包的人能讀到其中原文與附件。交給別人前，請確認內容適合分享。程式不會自動公開、上傳或寄出收藏。

程式尚未有發行者簽章。若 Windows 提醒來源未知，請先確認下載來源；不要為此停用系統防護。
